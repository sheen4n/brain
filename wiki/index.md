# Index

Top-level router for the wiki. Regenerated on every ingest.

Navigation uses plain Markdown links, not wiki-style links — index pages are navigational, not
graph nodes, so keeping them out of the link graph avoids false "broken link" reports from lint.

- [Entities](entities/index.md) — people, orgs, products, places (the graph hubs)
- [Concepts](concepts/index.md) — topics and themes
- [Sources](sources/index.md) — one page per ingested raw document
- [Open questions](open-questions.md) — unresolved contradictions and gaps
